focus-race-probe

Used to measure the race between extension.FocusWindow returning and a subsequent tine key / tine type actually being delivered to this window.

Focus another app before running tine. Then on the driver machine:

ssh archgnome 'source /tmp/tine-env.sh && \
    tine focus firefox && \
    tine type ABC'
ssh archgnome 'source /tmp/tine-env.sh && tine windows | grep focus-race'

The input field below captures every keydown. The page writes a monotonic counter + the concatenated keys received into document.title so the driver can read the tail over tine windows.

Expected (no race): title ends with ABC — all three keystrokes reached Firefox after focus.
Race (focus not yet delivered): title ends with '' or a prefix like 'C' — early keys were lost because wl_keyboard.enter hadn't fired yet for this window.
